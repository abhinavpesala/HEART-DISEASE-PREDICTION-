=============================================================================
TROUBLESHOOTING
=============================================================================

Problem: "ModuleNotFoundError: No module named 'sklearn'"
Solution: Run Step 1 again (pip install dependencies)

Problem: "FileNotFoundError: backend/models/tabular_model.joblib"
Solution: Run Step 2 first (python notebook.py) to generate model files

Problem: "Port 8000 already in use"
Solution: Change backend port in backend/main.py line:
  uvicorn.run(app, host="0.0.0.0", port=8001)

Problem: "Port 5173 already in use"
Solution: Vite will auto-increment to 5174, or edit vite.config.js:
  server: { port: 5174 }

Problem: "CORS error in browser console"
Solution: Make sure backend is running on http://localhost:8000

Problem: "Backend shows 'Models not found'"
Solution: Make sure dataset.csv is in root folder, then run notebook.py

=============================================================================
DEPLOYMENT TO RENDER + VERCEL
=============================================================================

BACKEND DEPLOYMENT (Render.com)
-------------------------------
1. Push to GitHub
2. Go to render.com → New → Web Service
3. Connect GitHub repo
4. Settings:
   - Build Command: pip install -r requirements.txt
   - Start Command: uvicorn backend.main:app --host 0.0.0.0 --port 8000
   - Environment: Add VITE_API_URL = https://your-render-app.onrender.com
5. Deploy

FRONTEND DEPLOYMENT (Vercel.com)
---------------------------------
1. Push to GitHub
2. Go to vercel.com → New Project → Import Git Repo
3. Settings:
   - Framework: Vite
   - Root Directory: frontend
   - Build Command: npm run build
   - Output Directory: dist
   - Environment: Add VITE_API_URL = https://your-render-app.onrender.com
4. Deploy
